Usage guide: https://youtu.be/UbcNekLgIK8

Prop Library (select existing or custom): directory of .blend files with objects or collections marked as assets that have the names of staticmesh and skeletalmesh objects from the game. Needed for prop support.

Game content root: the "content" folder of your fmodel exports. umap/ubulk files also go here next to the json files.

Recursive import: recursively import map json files mentioned in json files.

Import referenced ME UMAPs: Loads the .umap/.ubulk terrain mentioned in json file instead of making you import them separately.

Texture content root: Folder with subfolders "environment" etc. that contain your textures with the given extension.
